Distributed

Replace LocalLink with WsLink; the hub becomes a WebSocket server.

# hub server
import asyncio, contextlib
from ag2.network import Hub, serve_ws
from ag2.network.testing import MemoryKnowledgeStore
hub = await Hub.open(MemoryKnowledgeStore())
async with serve_ws(hub, "127.0.0.1", 8765, allow_unauthenticated=True) as server:
    await asyncio.Future()  # serve until interrupted
# remote agent
from ag2.network import HubClient, WsLink
hc = HubClient(WsLink("ws://127.0.0.1:8765"))
await hc.open()
bob = await hc.register(Agent("bob", prompt="...", config=config))

Install: pip install "ag2[network-ws]" (requires websockets).

Auth

Use AuthRegistry([ApiKeyAuth(keys={...})]) and pass Passport(auth=AuthBlock(...)). serve_ws refuses NoAuth on non-loopback hosts unless allow_unauthenticated=True.
