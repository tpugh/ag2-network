Lab 3

Workflow with a TransitionGraph and a Handoff tool.

Goal

Build a triage → specialist pipeline using the workflow adapter. Declare speaker order as data with a TransitionGraph, then add dynamic routing with a Handoff(target=...) tool and terminate with Finish.

What you will learn

  • How to declare a TransitionGraph (initial speaker, transitions, default target, max turns).
  • How built-in targets work: AgentTarget, TerminateTarget, RoundRobinTarget.
  • How built-in conditions work: Always, FromSpeaker, ToolCalled, ContextEquals.
  • How a tool returning Handoff(target=...) overrides the graph.
  • How Finish(summary=...) terminates the channel.

How to apply it

Use the workflow adapter to replace classic GroupChat + handoffs. It is ideal for triage/routing, pipelines, and any orchestration where you want the turn order to be inspectable data rather than imperative code.

Starter code

# examples/labs/lab3.py
import asyncio
from ag2 import Agent
from ag2.network import Hub, TransitionGraph, Handoff, Finish
from ag2.network.testing import MemoryKnowledgeStore
from common import make_config

async def main():
    config = make_config()
    hub = await Hub.open(MemoryKnowledgeStore(), ttl_sweep_interval=0)
    triage = await hub.register(Agent("triage", prompt="Triage the request; route to eng if technical.", config=config))
    eng = await hub.register(Agent("eng", prompt="Engineering specialist. One sentence.", config=config))
    graph = TransitionGraph.sequence([triage.agent_id, eng.agent_id])
    channel = await triage.open(type="workflow", target=[eng.agent_id],
        knobs={"graph": graph.to_dict()})
    await channel.send("The API is returning 500s.", audience=[eng.agent_id])
    await asyncio.sleep(20)
    await hub.close()
asyncio.run(main())

Tasks

  1. Run it. Confirm the channel closes with reason sequence_complete.
  2. Add a @triage.tool that returns Handoff(target=eng.agent_id) and observe dynamic routing.
  3. Add a @eng.tool that returns Finish(summary="done") to terminate early.
  4. Inspect hub.adapter_state(channel_id) to read turn_count and context_vars.

Key takeaways

  • Speaker order is data, not code — inspectable and serializable.
  • ToolCalled and Handoff let tools drive routing.
  • Context variables (ContextEquals) enable conditional branching.
  • The graph round-trips through TransitionGraph.to_dict() for distributed use.
