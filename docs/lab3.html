Lab 3

Workflow with a TransitionGraph and a Handoff tool.

Objective

Build a triage → specialist pipeline where a tool returns Handoff(target=...) to pick the next speaker dynamically.

Starter code

# examples/labs/lab3.py
import asyncio
from ag2 import Agent
from ag2.network import Hub, TransitionGraph, Handoff
from ag2.network.testing import MemoryKnowledgeStore
from common import make_config

async def main():
    config = make_config()
    hub = await Hub.open(MemoryKnowledgeStore(), ttl_sweep_interval=0)
    triage = await hub.register(Agent("triage", prompt="Triage the request.", config=config))
    eng    = await hub.register(Agent("eng", prompt="Engineering specialist.", config=config))
    graph = TransitionGraph(initial_speaker=triage.agent_id,
        transitions=[], default_target=None)  # TODO: fill in
    # Hint: use TransitionGraph.sequence([triage.agent_id, eng.agent_id])
    channel = await triage.open(type="workflow", target=[eng.agent_id],
        knobs={"graph": TransitionGraph.sequence([triage.agent_id, eng.agent_id]).to_dict()})
    await channel.send("The API is returning 500s.", audience=[eng.agent_id])
    await asyncio.sleep(20)
    await hub.close()
asyncio.run(main())

Tasks

  1. Replace the empty graph with TransitionGraph.sequence([...]).
  2. Add a tool on triage that returns Handoff(target=eng.agent_id) and observe dynamic routing.
  3. End the workflow with a Finish(summary=...) tool.
