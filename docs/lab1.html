Lab 1

First consulting channel — strict 1Q1R with auto-close.

Goal

Build the smallest possible AG2 network: one in-process hub, two agents, a consulting channel. Verify the hub auto-closes the channel after the respondent's reply and replay the transcript from the write-ahead log.

What you will learn

  • How to boot a Hub with a MemoryKnowledgeStore.
  • How hub.register(agent) stamps a hub-side agent_id and returns an AgentClient.
  • How alice.open(type="consulting", target="bob") creates a channel and how the adapter enforces 1-question-1-reply.
  • How the default handler runs Agent.ask and sends the reply.
  • How to replay a channel transcript from the hub's WAL.

How to apply it

Use the consulting adapter whenever you need a strict request/response: a coordinator asking a specialist a single question, a tool calling an expert agent, or any flow where you want automatic cleanup after one reply. The pattern scales to remote agents by swapping LocalLink for WsLink.

Starter code

# examples/labs/lab1.py
import asyncio
from ag2 import Agent
from ag2.network import EV_CHANNEL_CLOSED, EV_TEXT, Hub
from ag2.network.testing import MemoryKnowledgeStore
from common import make_config

async def main():
    config = make_config()
    hub = await Hub.open(MemoryKnowledgeStore(), ttl_sweep_interval=0)
    alice = await hub.register(Agent("alice", prompt="Ask one focused question and stop.", config=config))
    bob = await hub.register(Agent("bob", prompt="Answer in one short sentence.", config=config))
    channel = await alice.open(type="consulting", target="bob")
    await channel.send("What is the single most important property of a distributed system?", audience=[bob.agent_id])
    close_env = await alice.wait_for_channel_event(channel_id=channel.channel_id,
        predicate=lambda e: e.event_type == EV_CHANNEL_CLOSED, timeout=60.0)
    print("closed:", close_env.event_data.get("reason"))
    wal = await hub.read_wal(channel.channel_id)
    for env in wal:
        if env.event_type == EV_TEXT:
            speaker = "alice" if env.sender_id == alice.agent_id else "bob"
            print(f"{speaker}: {env.event_data['text']}")
    await hub.close()
asyncio.run(main())

Tasks

  1. Run the starter. Confirm it prints closed: 'consulting_complete' and two EV_TEXT lines.
  2. Change alice's question to something open-ended. Does bob still reply in one sentence?
  3. Try sending a second channel.send after the close. Observe the error (channel is terminal).
  4. Add a third agent and open a consulting channel to it. Compare WAL sizes.

Key takeaways

  • The Hub is the only authoritative state; clients are thin.
  • A channel_id is the unit of conversation; the WAL is keyed by it.
  • The consulting adapter auto-closes after initiator_sent + respondent_replied.
  • Every envelope is hub-stamped (id, timestamp, sender, audience, type, data).
