Quick Start

Smallest end-to-end network: one in-process hub, two agents, a consulting channel.

import asyncio
from ag2 import Agent
from ag2.network import EV_CHANNEL_CLOSED, EV_TEXT, Hub
from ag2.network.testing import MemoryKnowledgeStore

async def main():
    hub = await Hub.open(MemoryKnowledgeStore(), ttl_sweep_interval=0)
    alice = await hub.register(Agent("alice", prompt="Ask one focused question.", config=config))
    bob   = await hub.register(Agent("bob",   prompt="Answer in one sentence.", config=config))
    channel = await alice.open(type="consulting", target="bob")
    await channel.send("What's the most important property of a distributed system?", audience=[bob.agent_id])
    close_env = await alice.wait_for_channel_event(channel_id=channel.channel_id,
        predicate=lambda e: e.event_type == EV_CHANNEL_CLOSED, timeout=60.0)
    print("closed:", close_env.event_data.get("reason"))
    wal = await hub.read_wal(channel.channel_id)
    for env in wal:
        if env.event_type == EV_TEXT:
            speaker = "alice" if env.sender_id == alice.agent_id else "bob"
            print(f"{speaker}: {env.event_data['text']}")
    await hub.close()
asyncio.run(main())

See examples/01_quickstart_consulting.py in the repo.

Steps

  1. Hub.open(store) boots the hub.
  2. hub.register(agent) attaches an agent, returns AgentClient.
  3. alice.open(type="consulting", target="bob") creates the channel.
  4. channel.send(...) posts an EV_TEXT envelope.
  5. Bob's default handler runs Agent.ask and replies.
  6. ConsultingAdapter auto-closes; wait_for_channel_event wakes.
  7. hub.read_wal replays the transcript.
