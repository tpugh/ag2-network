AG2 Network

AG2's open-source multi-agent runtime. Build hubs, register agents, open channels, plug in your own adapters, and add rules.

The ag2.network module turns one or more Agent instances into a multi-agent network: a hub-and-spoke topology where a central Hub coordinates channel-based, protocol-driven exchanges between named agents. It is fully opt-in — bare Agent keeps working standalone.

Mental Model

Hub (registry, audit log, channels, WAL, sweepers)
   │  LocalLink (in-process) or WsLink (WebSocket)
   ├── AgentClient alice  (Agent)
   ├── AgentClient bob    (Agent)
   └── HumanClient carol  (human)

Core Concepts

  • Hub — authoritative state.
  • Passport / Resume — identity and capability claims.
  • Rule — per-agent governance.
  • AgentClient / HumanClient — agent/human participants.
  • Channel — bounded multi-party exchange governed by an adapter.
  • Envelope — hub-stamped wire record.
